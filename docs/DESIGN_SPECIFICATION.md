# Portfolio Design Specification

## Layout Requirements (1006x799px)

### Background
- Dark purple-black gradient
- Colors: #0a0a0a (black) → #4a0e4e (purple) → #6a1b9a (accents)

### Header Section (Top Center)
- **Main Title**: "SAI"
  - Font: Elegant sans-serif
  - Size: 80pt
  - Color: White
  - Weight: Bold
  - Alignment: Center

- **Subtitle**: "Dream Build Craft & Achieve."
  - Font: Sans-serif italic
  - Size: 32pt
  - Color: White
  - Alignment: Center
  - Position: Below main title

### Action Section (Below Subtitle)
- **Button**: "Let's Talk"
  - Style: Rounded purple button
  - Text: White
  - Glow: Subtle purple glow effect
  - Position: Left-aligned
  
- **Icon**: Small white circle icon next to button

### Skill Badges (Below Button)
Two horizontal badges side-by-side:

1. **Left Badge**: "Full Stack Developer"
   - Icons: Web and Salesforce
   - Style: Rounded corners
   - Background: Purple
   - Text: White

2. **Right Badge**: "Automation Flow"
   - Icons: AI and data
   - Style: Rounded corners
   - Background: Purple
   - Text: White

### Profile Photo (Right Side)
- **Type**: Circular profile photo
- **Subject**: Young Indian male professional
- **Age**: Mid-20s
- **Appearance**: 
  - Short black hair
  - Formal shirt
  - Smiling confidently
- **Position**: Right side, overlapping description section

### About Me Section (Left Side)
- **Header**: "About Me"
  - Font: Medium white bold
  - Position: Below badges

- **Description Text**:
  ```
  Software engineer in cybersecurity, AWS cloud, Python, and AI solutions 
  since 2023. With a growing passion for secure workflows, I enjoy working 
  with teams to deliver innovative data-driven solutions that streamline 
  processes and drive efficiency. Wrangling Salesforce into doing bedrock 
  or AI a little more intelligently—it's all about that perfect blend.
  ```
  - Font: Clean sans-serif
  - Line height: 1.6
  - Color: White with subtle purple highlights
  - Alignment: Left

## Color Palette
- Primary Black: #0a0a0a
- Primary Purple: #4a0e4e
- Accent Purple: #6a1b9a
- Text White: #ffffff
- Glow Purple: rgba(106, 27, 154, 0.5)

## Typography
- Main Title: 80pt Bold Sans-serif
- Subtitle: 32pt Italic Sans-serif
- Headers: Medium Bold Sans-serif
- Body: Regular Sans-serif, line-height 1.6
- Buttons: Semibold Sans-serif

## Spacing
- Title to Subtitle: 20px
- Subtitle to Button: 40px
- Button to Badges: 30px
- Badges to About: 40px
- Line spacing: 1.6

## Effects
- Button glow: box-shadow with purple color
- Gradient background: radial or linear gradient
- Profile photo: Circular crop with subtle border
- Badges: Slight elevation/shadow

## Responsive Considerations
- Desktop: 1006x799px as specified
- Tablet: Stack badges vertically
- Mobile: Single column layout
